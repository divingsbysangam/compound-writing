# CLAUDE.md

This repository contains the `sangam-writing-plugin`, a context-first compounding writing toolkit for *Divings by Sangam*.

## Commands
All skills are exposed as `/sw-*` commands. Run `/sw-commands` to inspect the full catalog or `/sw-help` for guidance.

Key commands:
- `/sw-scribe` — Front-door orchestrator.
- `/sw-interview` — Mine real memories, numbers, and build scenes.
- `/sw-outline` — Build 4-part short-form or 6-beat long-form structures.
- `/sw-draft` — Generate structural scaffolds (scaffolding default).
- `/sw-ai-check` — Zero em dashes, mandatory contractions, banned word elimination.
- `/sw-voice-check` — Audit against `context/VOICE.md`.
- `/sw-atomize` — Transform Substack essay into LinkedIn caption & carousel.
- `/sw-save` — Compound editorial lessons and preferences into context files.

## Non-Negotiables
- Em dashes: ZERO.
- Contractions: Always used naturally.
- Never hallucinate facts, metrics, or personal scenes.
- Substack drafts default to scaffolds.
