# Divings by Sangam Help

This toolkit guides writing from initial raw memory through publication-ready Substack essays and LinkedIn carousels, compounding your lessons as you write.

## Where to Begin

| You Have | Start With |
|---|---|
| A loose topic or rough memory | `sw-interview` |
| No clear idea yet | `sw-brainstorm` |
| Interview notes or bullet points | `sw-thesis` then `sw-outline` |
| An outline or scaffold | `sw-draft` (scaffolding default) |
| A rough draft to polish | `sw-ai-check` followed by `sw-voice-check` |
| Structural doubts | `sw-dev-edit` |
| High-stakes claims to stress-test | `sw-objections` or `sw-asshole` |
| An approved Substack essay to repurpose | `sw-atomize` |
| An edit you want the system to remember forever | `sw-save` |

Use `sw-scribe` whenever you want the agent to automatically pick the right step.
