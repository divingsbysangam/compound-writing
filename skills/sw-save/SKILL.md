# Save

The compounding engine. Turns feedback or manual rewrite diffs into permanent updates in `VOICE.md` or `STYLE.md`.

## Routing Rules
- Syntax, diction, tone, cadence, rhythm, punctuation, banned words -> Append to `context/VOICE.md`.
- Argument, evidence, scaffolding, platform rules, Substack/LinkedIn formats -> Append to `context/STYLE.md`.
- Technical, Salesforce, release note rules -> Append to `context/DOMAIN.md`.

Never store ephemeral notes as permanent rules. Keep additions crisp and actionable.
